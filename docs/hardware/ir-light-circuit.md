# IR ライト回路

940nm 赤外線 LED をトランジスタスイッチ経由で GPIO18 から PWM 制御するための回路。

## 部品

- 940nm 赤外線 LED × 6（3個直列の列を2系統、並列）
- 47Ω 抵抗（1/4W, 5%）× 2（各系統の電流制限用）
- 47Ω 抵抗（1/4W, 5%）× 10（ベース抵抗の代用。直列で合計約470Ω。1kΩ の手持ちが無かったため）
- 2SC1815（NPN トランジスタ, TO-92）× 1

## 回路

```
Pi 5V ──┬── [IR LED]-[IR LED]-[IR LED] ── [47Ω] ──┐
        │                                          ├── トランジスタ C（コレクタ）
        └── [IR LED]-[IR LED]-[IR LED] ── [47Ω] ──┘

トランジスタ E（エミッタ）── Pi GND

Pi GPIO18 ── [47Ω × 10 直列 ≒ 470Ω] ── トランジスタ B（ベース）
```

GPIO18 が HIGH の間、ベース抵抗を通してベース電流が流れ、トランジスタが導通して
5V → LED → 47Ω → トランジスタ → GND の経路に電流が流れる。PWM で HIGH の割合を
変えると平均輝度が変わる。

## ブレッドボード配置

ブレッドボードは A-F / G-L の2ブロック構成（中央に溝）、列は 1-30。今回の回路は
A-F ブロックのみを使用し、下部の電源レールは使わない。

## ユニバーサル基板への移行（本番ビルド）

ブレッドボードでの検証で回路が正常に動作することを確認済み。長期設置に向けて、接触不良のリスクを下げるためユニバーサル基板にはんだ付けで組み直す。

### 使用基板

- 種別: ユニバーサル基板（片面、穴あき・非連結）
- 材質: CEM-3
- 長辺: 47mm、短辺: 36mm、厚み: 1mm
- ランドピッチ: 2.54mm（長辺・短辺とも）
- 穴径: 1mm、取付穴径: 3.2mm

### 部品変更点

- ベース抵抗をブレッドボード検証時の 47Ω×10 直列（合計約470Ω、1kΩ が手元に無かったための代用）から、**1kΩ 抵抗1本**に統一する。はんだ点・故障点を減らすため
- その他の部品（940nm 赤外線 LED×6、電流制限用47Ω×2、2SC1815×1）は変更なし。回路構成（トポロジー）は「回路」節の図のとおり

### 基板上の端子

- 5V 入力
- GND
- GPIO18 入力
- LED 出力（系統1・系統2をまとめて1本のケーブルで LED ケースへ配線してよい）

（穴位置・実装レイアウトは、はんだ付け時に現物合わせで決める。ブレッドボード検証時のような穴番号表は作らない）

## LED 外付けケースと設置

### ケース

- タカチ SW-40B（幅30mm×奥行40mm×高さ20mm、ABS樹脂）
- LED（直径5mm）用の穴を6個、2列×3個・中心間隔約10mmで配置し、ピンバイス（5mm対応ビット）で開ける。位置決めは千枚通し等で軽く印をつけてから穴を開けると精度が出やすい
- LED はケース内側から差し込み、ホットボンド等で固定
- ケーブル引き出し用に側面へ1つ穴を追加し、ドライバ基板とは2〜3芯ケーブルで接続

### 設置方針

- カメラ（Camera Module 3 NoIR Wide）の近くに1ケースへ集約して設置する（ケージ全体への分散配置はしない）
- カメラと同様、ケージ外・ガラス越しに設置する。水がかかる想定はないため防水対応は不要

### 反射対策

ガラス越しの撮影・照明では2種類の反射に注意する。

1. 周囲光（部屋の照明等）がガラス表面で反射してレンズに映り込む
2. IR LED 自身の光がガラス面で正反射し、そのままレンズへ跳ね返る

対策:

- レンズおよび LED ケース前面それぞれに、黒いスポンジ・フェルト等でスカード（ガラスに軽く密着させて隙間からの光の出入りを防ぐ簡易フード）を取り付ける
- カメラと LED を同軸・同一位置に置かず、数cm程度のオフセットを設ける（正反射光がそのままレンズへ戻る経路を避けるため）
- ガラスに対して垂直（法線方向）に構えず、角度を付けて設置する（既存の「斜め下向き」設置方針と整合）

### 固定方法（2段階）

カメラの固定方法も未定のため、以下の2段階で進める。

**ステージ1（検証・仮設置、既製品のみ）**

- 自由雲台付きミニ三脚（フレキシブルレッグ）× 2（カメラ用・LED ケース用を独立して動かせるようにする）
- Camera Module 3 用の三脚穴付きケース/ブラケット × 1（裸基板のままでは三脚に固定できないため）
- 黒いスポンジ/フェルトシート（レンズ・LED 前面のスカード用）
- 分度器・定規（位置が決まったら数値化するため）

手順: カメラ・LED をそれぞれ独立した三脚で仮設置し、部屋の照明あり/なし両方でプレビュー映像を確認しながら、反射・ハレーションが消える距離・角度を探る。見つかった位置関係（オフセット距離・角度）を記録する。

**ステージ2（本設置、将来対応・本 PR の範囲外）**

ステージ1で確認した位置関係をもとに、カメラと LED ケースを一体で固定するブラケットを CAD 設計し、3Dプリント代行サービス（例: 3Dプリントエクスプレス、3D Data Japan など、STL アップロードで個人・小ロット発注可能な国内サービス）へ発注して本設置用に置き換える。3Dプリンタは所有していないため代行を利用する。

## 安全上の注意

- GPIO への通電（テスト点灯・本番デプロイ後の初回起動含む）は、実行前に必ず内容を確認する
- 明るさ（PWM duty cycle）は固定値の決め打ちをせず、生体への影響とカメラの映りを見ながら
  実機で調整して決める
