# IR ライト回路

940nm 赤外線 LED をトランジスタスイッチ経由で GPIO18 から PWM 制御するための回路。

## 部品

- 940nm 赤外線 LED × 6（3個直列の列を2系統、並列）
- 47Ω 抵抗（1/4W, 5%）× 2（各系統の電流制限用）
- 47Ω 抵抗（1/4W, 5%）× 10（ベース抵抗の代用。直列で合計約470Ω。1kΩ の手持ちが無かったため）
- 2SC1815（NPN トランジスタ, TO-92）× 1

## 回路

```
Pi 5V ──┬── [IR LED]-[IR LED]-[IR LED] ── [47Ω] ──┐
        │                                          ├── トランジスタ C（コレクタ）
        └── [IR LED]-[IR LED]-[IR LED] ── [47Ω] ──┘

トランジスタ E（エミッタ）── Pi GND

Pi GPIO18 ── [47Ω × 10 直列 ≒ 470Ω] ── トランジスタ B（ベース）
```

GPIO18 が HIGH の間、ベース抵抗を通してベース電流が流れ、トランジスタが導通して
5V → LED → 47Ω → トランジスタ → GND の経路に電流が流れる。PWM で HIGH の割合を
変えると平均輝度が変わる。

## ブレッドボード配置

ブレッドボードは A-F / G-L の2ブロック構成（中央に溝）、列は 1-30。今回の回路は
A-F ブロックのみを使用し、下部の電源レールは使わない。

### LED・抵抗（電流制限用）

| 部品 | 足 | 穴 |
|---|---|---|
| LED1（系統1・1個目） | アノード / カソード | A1 / A2 |
| LED2（系統1・2個目） | アノード / カソード | B2 / B3 |
| LED3（系統1・3個目） | アノード / カソード | C3 / C4 |
| 47Ω（系統1） | 片足 / もう片足 | D4 / D5 |
| LED4（系統2・1個目） | アノード / カソード | A7 / A8 |
| LED5（系統2・2個目） | アノード / カソード | B8 / B9 |
| LED6（系統2・3個目） | アノード / カソード | C9 / C10 |
| 47Ω（系統2） | 片足 / もう片足 | D10 / D11 |

### トランジスタ

2SC1815（刻印 `C1815` を確認済み）。平らな面（印字面）を手前に、足を下にして
見たときに左から E-C-B。

| 足 | 穴 |
|---|---|
| E（エミッタ） | A15 |
| C（コレクタ） | A16 |
| B（ベース） | A17 |

### コレクタの結線（ジャンパー線）

ブレッドボード内のジャンパー線（コレクタ結線・GND）はオス-オス。Pi との接続用（5V×2・GND・GPIO18）はオス-メス（ブレッドボード側がオス、Pi のピンヘッダにかぶせる側がメス）。

| from | to |
|---|---|
| E5 | B16 |
| E11 | C16 |

### ベース抵抗チェーン（47Ω × 10、合計約470Ω）

列を1つずつ進めながら行を1段ずつずらす（A→B→C→D→E→F→A…と循環）。

| 抵抗 | 片足 | もう片足 |
|---|---|---|
| R1 | B17（トランジスタBと同列） | B18 |
| R2 | C18 | C19 |
| R3 | D19 | D20 |
| R4 | E20 | E21 |
| R5 | F21 | F22 |
| R6 | A22 | A23 |
| R7 | B23 | B24 |
| R8 | C24 | C25 |
| R9 | D25 | D26 |
| R10 | E26 | E27 |

### GND（ジャンパー線）

| from | to |
|---|---|
| B15（エミッタと同列） | A29 |

## Raspberry Pi との接続（40pin ヘッダ、物理ピン番号）

| Pi 側 | 行き先（ブレッドボード） |
|---|---|
| 物理ピン2（5V） | D1 |
| 物理ピン4（5V） | D7 |
| 物理ピン6（GND） | B29 |
| 物理ピン12（GPIO18） | F27 |

## 安全上の注意

- GPIO への通電（テスト点灯・本番デプロイ後の初回起動含む）は、実行前に必ず内容を確認する
- 明るさ（PWM duty cycle）は固定値の決め打ちをせず、生体への影響とカメラの映りを見ながら
  実機で調整して決める
